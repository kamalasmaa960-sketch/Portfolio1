# Asmaa Digital Studio — Cloudflare Durable Objects

## محتويات الحزمة
- `public/index.html`: واجهة الموقع
- `worker.js`: واجهة API وقاعدة البيانات Durable Object
- `wrangler.toml`: إعدادات Cloudflare Worker وSQLite-backed Durable Object

## النشر من الموبايل/التابلت
1. ارفعي محتويات هذا المجلد إلى مستودع GitHub.
2. افتحي Cloudflare Dashboard ثم Workers & Pages وأنشئي Worker متصلًا بالمستودع، أو استخدمي Wrangler من بيئة تطوير.
3. اجعلي جذر المشروع هو المجلد الذي يحتوي `wrangler.toml`، ثم انشريه.
4. بعد النشر افتحي رابط الموقع واختبري `/api/health`؛ يجب أن يظهر `ok: true`.
5. افتحي لوحة التحكم وأضيفي/عدّلي خدمة، ثم افتحي الموقع من جهاز آخر. يجب أن تظهر التعديلات بعد إعادة التحميل إذا كانت المزامنة متصلة.

## قاعدة البيانات
يستخدم المشروع Durable Object باسم `PortfolioDatabase` مع SQLite storage عبر `new_sqlite_classes`. Cloudflare ينشئ التخزين عند أول طلب. لا تحتاجين لإنشاء قاعدة بيانات يدويًا من لوحة التحكم.

## تنبيه مهم جدًا عن الأمان
هذه الحزمة تضيف المزامنة الدائمة، لكنها لا تضع بعدُ تسجيل دخول إداري آمنًا على الخادم: واجهة الإدارة الحالية وتحقق الدخول داخل HTML ويمكن تجاوزهما، كما أن API الكتابة متاح علنًا. **لا تنشريها كنسخة إنتاجية قبل إضافة مصادقة خادمية**. بيانات الدخول `Asmaa / 444444` هي بيانات الواجهة الحالية وليست حماية حقيقية. لا تخزني بيانات شخصية حساسة.

## الصور
الصور المضافة من الجهاز تُحوّل إلى Data URL وتُحفظ داخل سجل الموقع؛ هذا يستهلك مساحة قاعدة البيانات بسرعة. استخدمي روابط صور مستضافة خارجيًا، أو صورًا صغيرة جدًا. الحد الحالي للطلب السحابي أقل من نحو 900 كيلوبايت.


## طرق التواصل وتعديل الصفحة الرئيسية
من لوحة التحكم > التواصل والمظهر والأمان يمكنك إضافة البريد والهاتف وواتساب وروابط Facebook وInstagram وTelegram، وتعديل العنوان والوصف والأزرار الرئيسية وألوان الموقع. اتركي وسيلة التواصل فارغة لإخفائها.


## تحديث طرق التواصل
تم حذف التواصل بالبريد الإلكتروني من الواجهة. أضيفي رقم الهاتف من لوحة التحكم ليظهر بوضوح كبطاقة كبيرة قابلة للنقر للاتصال، وتظهر واتساب وباقي الشبكات في بطاقات مرتبة. بعد تحديث `public/index.html` أعيدي نشر المشروع على Cloudflare.
